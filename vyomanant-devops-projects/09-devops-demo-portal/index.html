Deployment note: The launch links point to ports on the same hostname as this portal. Each application must be running separately and its port must be accessible. This dashboard does not query Docker, so it does not display real-time container status.

Deployment Blueprint

Build and run this portal as a standalone NGINX container.

STEP 01

Prepare files

Upload index.html, Dockerfile and nginx.conf into a directory on your Ubuntu EC2 host.

STEP 02

Build the image

Build the container image with Docker and publish port 8090 on the host.

STEP 03

Test and iterate

Verify the portal, launch each running application and extend the pipeline to CI/CD.

Quick deployment commands

docker build -t vyomanant-demo-portal:v1 .
docker run -d --name vyomanant-demo-portal --restart unless-stopped -p 8090:80 vyomanant-demo-portal:v1
docker ps
docker logs vyomanant-demo-portal
curl -I http://localhost:8090
